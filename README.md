# 프로그램 모음

AI 도구(Codex, Claude)를 활용해 만들고 검증한 프로그램을 프로젝트별 폴더로 나눠 관리합니다. 각 결과물에서 본인이 한 일과 AI가 한 일, 검증 결과는 [AI 활용 경험과 결과물](./AI_활용_경험.md)에 정리했습니다.

| 프로그램 | 하는 일 | 설명, 다운로드 |
| --- | --- | --- |
| **Codex 사용량 위젯** | Windows 바탕화면에서 Codex 사용량과 초기화 시각 확인 | [사용량 위젯 폴더 열기](./codex-usage-widget/) |
| **내 공고 작업실** | 채용공고 수집, 전공, 학력, 경력 필터, 공고 묶음과 원문 확인 | [공고 프로그램 폴더 열기](./job-workbench/) |
| **월간 수요검토 에이전트 프로토타입** | 수요예측 검토 흐름(독립 예측, 근거 분류, 검토표, 연결표 갱신)을 가상 데이터로 시연 | [프로토타입 폴더 열기](./demand-review-prototype/) |

## Codex 사용량 위젯

[codex-usage-widget](./codex-usage-widget/) 폴더에 실행 파일, Python 소스, 사용 설명이 있습니다.

## 내 공고 작업실

[job-workbench](./job-workbench/) 폴더에 실행 안내와 공개용 소스 ZIP이 있습니다.

현재 공고 프로그램은 **소스 배포본**입니다. Node.js 22 이상과 의존성 설치가 필요하며, 상세 실행 방법은 해당 폴더의 README를 참고하세요.

개인 수집 공고, 메모, 검색조건, 인증정보는 공고 프로그램 소스 ZIP에 포함하지 않았습니다.

## 월간 수요검토 에이전트 프로토타입

[demand-review-prototype](./demand-review-prototype/) 폴더에 Python 소스와 실행 안내가 있습니다. LOTTE AX Challenge 2026 예선 기획안을 검증하기 위한 것이며, **모든 데이터는 가상**입니다.
