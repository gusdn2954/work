# 내 공고 작업실

[공개용 소스 ZIP 내려받기](./job-workbench-source.zip)

공고 수집, 전공·학력·경력 필터, 채용 묶음, 원문 이동, 메모·준비 기록, 한국어 이미지 OCR, 수집 진행률을 제공하는 로컬 프로그램입니다.

## 실행 방법

1. 소스 ZIP을 내려받아 압축을 풉니다.
2. Node.js 22 이상을 설치합니다.
3. 압축을 푼 위치에서 아래 명령을 실행합니다.

```powershell
cd job-workbench/jobs
npm install
npx playwright install chromium
npm start
```

브라우저에서 http://127.0.0.1:42637/ 을 엽니다. 처음에는 공고 0건으로 시작하며 전공과 사이트, 검색 조건을 정한 뒤 공고 가져오기를 누릅니다. 자세한 안내는 ZIP 안의 README.md를 참고하세요.

## 배포 범위와 검증

- 코드 및 테스트 등 78개 파일을 포함한 소스 패키지입니다. 설치 파일이나 웹 호스팅 서비스가 아닙니다.
- 제작자의 수집 공고·메모·경험·검색조건·로그·인증정보·원래 Git 이력은 포함하지 않았습니다.
- 배포 준비본에서 단위 검사 136개, 브라우저 검사 33항목을 통과했습니다. 실제 외부 사이트 전체 수집 및 다른 PC 실행은 이번 검증 범위에 포함되지 않습니다.
- Windows 한국어 OCR은 해당 PC의 언어 인식 구성 요소가 필요합니다.
- 소스 ZIP 게시 자체가 서명 없는 설치기의 스마트 앱 컨트롤 차단을 해결하지는 않습니다.
- 기존 저장소의 Codex 사용량 위젯과 별개인 프로젝트입니다.
