## Codex 사용량 위젯

[codex-usage-widget](./codex-usage-widget/) 폴더에 실행 파일, Python 소스, 사용 설명이 있습니다.

## 내 공고 작업실

[job-workbench](./job-workbench/) 폴더에 실행 안내와 공개용 소스 ZIP이 있습니다.

현재 공고 프로그램은 **소스 배포본**입니다. Node.js 22 이상과 의존성 설치가 필요하며, 상세 실행 방법은 해당 폴더의 README를 참고하세요.

개인 수집 공고·메모·검색조건·인증정보는 공고 프로그램 소스 ZIP에 포함하지 않았습니다.
